# Army Rank Insignia Sources

Insignia sourced from the [Wikimedia Commons category supplied by the user](https://commons.wikimedia.org/wiki/Category:SVG_military_rank_insignia_of_the_United_States_Army). Each linked file page identifies its artwork as public domain. No rank abbreviation is used as a substitute emblem. PVT / E-1 has no worn rank insignia and displays rank text only.

PV2, PFC, SPC, CPL, SGT, and SSG use the downloaded original SVGs. Other ranks use Wikimedia’s standard 500-pixel PNG renderings of their source SVGs because the original-file server returned HTTP 429 with a 600-second retry interval. Native rendering preserves the source artwork and colors; no insignia is redrawn or recolored.
