# The Leaders Book

**Your digital Army leader’s book, wherever you lead.**

Keep Soldier profiles, training records, fitness scores, and field references together in one easy-to-use app. Stay organized, know your team, and keep the mission moving.

Built using Apple’s Human Interface Guidelines (HIG) and designed for **iPhone Duo**.
